# 🧩 Algorithm Study Archive

한신대학교 **알고리즘 소모임 Solvers** 활동을 통해 학습한
알고리즘 개념과 문제 풀이 코드를 기록하는 개인 아카이브입니다.

소모임에서 제공되는 **알고리즘 학습 PPT를 통해 개념을 공부한 뒤**,
관련 문제를 직접 해결하면서 내용을 복습하고 문제 해결 능력을 기르는 것을 목표로 합니다.

* 소속: **한신대학교 알고리즘 소모임 Solvers**

## 📝 Study Process

Solvers 활동에서는 다음과 같은 방식으로 학습하고 있습니다.

1. 알고리즘 학습 PPT를 통해 개념 이해
2. 예제 코드 및 동작 과정 확인
3. Jungol 관련 문제 풀이
4. 직접 코드 작성 및 실행
5. 오답 발생 시 원인 분석
6. 풀이 과정에서 부족했던 개념 복습
7. 학습한 문제와 코드를 저장소에 기록
